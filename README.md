Interaktive Jupyter-Notebooks zur PARIS-API und den Open-Data-Angeboten der Stadt Zürich.

### Pandas & Zürich Open Data Tutorial

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/DonGoginho/sim/HEAD?filepath=pandas_zurich_opendata_tutorial.ipynb)

## Was steckt drin?

| Notebook | Inhalt |
|---|---|
| `paris_api_gemeinderat_zuerich_tutorial.ipynb` | Abfragen der PARIS-API: Ratsmitglieder, Geschäfte, Sitzungen, Parteienverteilung |
| `pandas_zurich_opendata_tutorial.ipynb` | Datenanalyse mit pandas auf Basis der offenen Stadtdaten Zürich |
