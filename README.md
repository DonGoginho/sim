# PARIS-API Tutorial – Gemeinderat Zürich

Interaktives Jupyter-Notebook zur PARIS-API der Stadt Zürich: Ratsmitglieder, Geschäfte, Sitzungen, Parteienverteilung.

## Im Browser starten (kein Python nötig)

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/DonGoginho/sim/HEAD?filepath=paris_api_gemeinderat_zuerich_tutorial.ipynb)

Auf den Badge klicken → Notebook startet direkt im Browser, keine Installation nötig.

## Auf RenkuLab importieren

1. [renkulab.io/projects/new](https://renkulab.io/projects/new?url=https://github.com/DonGoginho/sim) aufrufen
2. Projekt erstellen → Notebook `paris_api_gemeinderat_zuerich_tutorial.ipynb` öffnen → Loslegen
